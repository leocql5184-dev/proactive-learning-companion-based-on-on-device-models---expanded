# 智伴同行比赛交付

> 历史比赛包说明。当前公开入口默认使用 **Windows GGUF + llama.cpp**，以 [README.md](README.md) 和 [发布指南](docs/PUBLISH_GITHUB.md) 为准。公开源码不含签名材料、原始学习记录或模型权重；下文描述的是旧比赛交付内容。

旧比赛包使用 MindSpore Lite Qwen3 `.ms`。
解压到英文路径，双击 **打开学伴.cmd**，浏览器地址 http://127.0.0.1:8875。
Windows x64 的 Node、Python、NumPy、分词器和 CPU 推理运行库随工程提供，启动无需联网下载。

为保证 ZIP 小于 2 GB，包内保存完整 qwen-prefill.ms 和 decode 模型的无损差分。
首次启动在本地还原 qwen-decode.ms 并验证原始 SHA-256，也可先双击 **准备模型.cmd**。
还原后为两个原始 `.ms` 文件，权重未改动。请预留至少 5 GB 磁盘空间。

submission/智伴同行-debug.hap 是已签名 Debug 包，附签名校验报告。
证书主体“智伴同行”，为新建本地测试证书，未绑定设备；并非华为签发的真机调试证书。
指定华为设备安装需要通过华为开发者账户取得调试证书及对应设备 Profile 后重新签名。
比赛通知要求已签名包，不代表本次已验证该本地证书可安装到评委设备。

鸿蒙工程和 `.ms` 原生接口一并提供，DevEco 构建已验证，手机端运行未实测。
鸿蒙聊天页导入两个 `.ms` 和 tokenizer.json；先运行准备模型.cmd 还原 decode。
电脑端学习、认知/符号核查、因果评估原型、主动介入、反馈与成长记录沿用现有流程。
真实教学因果效果、其他设备性能及任意学科能力不属于本次测试结论。

验收见 docs/SUBMISSION_MS.md。其他文档中 GGUF 和旧端口的描述为历史记录，以本说明为准。
签名材料和重建所需配置包含在工程内，仅用于本项目 Debug 交付。
