## 1. 项目应该回答的三个问题

1. **学生现在可能卡在哪里？** 从连续作答、解释、提示前后表现估计知识点掌握与当次认知状态，保留不确定性。
2. **现在采取哪一种帮助，可能比其他帮助更有效？** 比较介入后的独立作答或迁移结果；不能把“提示后答对”直接解释为提示的因果效果。
3. **为什么相信这次判断？** 神经模型识别自然语言证据，符号模块检查数学关系、前提与矛盾，最终给出可重放的推理路径。

研究主线建议表述为：**基于可校准认知状态与可审计神经符号推理的主动学习介入；通过干预记录逐步估计策略效果。**

这不是给现有规则模块换名字。新的模块必须能根据证据更新参数或后验，能被反例推翻，并在对照实验中证明增加模块是否有价值。

完全消除先验并不现实：题目知识关系、状态定义、因果识别假设都是建模选择。目标应是让这些假设明确、可检查，并让状态概率、观测误差、关系强度和行动效果尽可能从数据估计。授权、删除、拒绝、勿扰等确定性约束继续保留，它们不承担学习状态识别。

## 3. 最小完整链路

```text
授权的事件 + 当前题目 + 学生解释
  → EvidenceBuilder：作答条件、提示使用、解释片段、来源与缺失信息
  → NeuralEvidence：概念/错误候选、证据位置、校准概率或 UNKNOWN
  → SymbolicReasoner：核对前提、推导关系、冲突与反例
  → CognitiveState：各知识点的动态后验 + 当次困惑候选
  → InterventionEstimator：候选帮助的结果预测与因果证据等级
  → Policy：在授权范围内选择保持安静/核查问题/不同提示方式
  → 独立后测、迁移题与用户反馈
  → 更新状态、关系/观测参数与行动效果；保留版本
```

所有环节返回 `evidenceIds`、`modelVersion`、`graphVersion`、`uncertainty` 和 `status`。推理解释由真实计算轨迹生成，不让语言模型事后编造理由。

## 4. 认知状态：先做能学习参数的概率模型

### 首版状态

- **知识状态**：按知识点维护掌握概率的后验，以及观测数量和来源；提示后正确与独立正确使用不同观测模型。
- **当次状态**：理解不确定、概念冲突、需要进一步核查，保留多种候选。停顿本身仅是行为事实。
- **过程特征**：自我检查、提示依赖、错误修正等先记录事实，跨会话证据充分后才讨论倾向。
- 情绪仍优先使用自报；不能把认知模型变成人格诊断器。暂不输出无法校准的“认知负荷 87%”等数值。

### 计算方案

先采用小规模隐状态模型/贝叶斯知识追踪（BKT）作为可解释基线；估计初始掌握、学习转移、失误和猜测参数。后续增加时间间隔、题目难度和提示条件，避免同一正确答案无差别累加。

更新形式：`p(K_t | evidence_1:t) ∝ p(evidence_t | K_t, item, assistance) × predicted_prior(K_t)`。

模型参数需要从按学生划分的训练轨迹估计（例如约束最大似然/EM），不能把四个手工常数包装成已学习模型。数据不足时明确标为先验/演示后验；没有证据的知识点显示 UNKNOWN，不把先验值呈现为实测掌握率。

第二步训练小型时序神经网络作为观测编码器，输出可校准的观测似然或错误类别；显式概率状态继续承担记忆和解释。不要在只有少量合成样本时直接以大型 DKT 替换全部模型。

**验收**：按学生隔离、按时间预测下一次独立作答；报告 log loss、Brier score、校准曲线和覆盖率，AUROC 仅在标签有足够变化时使用。演示“答对但解释矛盾”“提示后答对”“延迟迁移失败”导致不同后验；未知判分不更新能力。

## 5. 因果关系：把知识关系与介入效果分开

### A. 知识依赖结构

`指数含义 → 对数定义` 可作为待复核的先修假设，用于选择核查问题。图上有一条边不代表已证明“补这个知识点会使学生学会另一个知识点”。关系要标注 `prerequisite_hypothesis`、`mathematical_entailment` 或 `estimated_intervention_effect`，避免混用。

### B. 干预效果模型

定义：介入前状态 `X`，行动 `A`，独立后测结果 `Y`。目标是比较相同情境下两种行动的期望结果，例如：

`Δ(X) = E[Y | do(A=概念核查), X] − E[Y | do(A=分步提示), X]`。

首版动作只选两个经审核的低风险教学方式；“不介入”可作观察基线，不能为了实验阻断学生主动求助。结果优先是后续独立迁移题表现，接受提示、恢复尝试和自报有帮助分别记录，不能混成“认知提升”。

事件中记录 `decisionId`、介入前状态快照、允许的动作集合、所选动作、选择概率（propensity）、策略版本、后测时间窗、是否缺失及原因。必须保存介入前快照，不能把提示后的行为作为决策前特征。

实施分三档：

1. **工程演示**：已知结构的合成学习环境，检验能否恢复预设效应、识别混杂和拒绝无重叠数据。展示“模拟”，只证明估计器正常工作。
2. **观察性探索**：真实授权日志中做结果预测、分层和敏感性分析，输出相关性或依赖假设。现有确定性策略没有动作重叠时，不计算伪因果提升。
3. **前瞻评估**：在另行明确的用户研究方案中，对允许动作进行随机化或设计可识别的比较；记录实际分配概率。满足一致性、可交换性/随机化、正值性和结果测量条件后，比较 IPS/双重稳健估计与直接结果模型。报告有效样本量、区间和缺失率。

展示个体反事实“你如果休息就一定做对”是不成立的。即使有群体平均效果，也只能作为带不确定性的行动依据。

**验收**：构造“困难学生更常被提示”的混杂案例，朴素成功率与真实效应方向不同，估计器在满足识别条件时能够恢复；无动作重叠、倾向概率为零、缺失后测或不支持的知识点必须拒绝估计。

## 6. 神经符号计算：让模型提证据，让结构检查推理

首版选择**对数定义—指数关系**这一小子域，复用现有题目与教学内容，再扩展二次方程判别式。

### 神经部分

Qwen 将自然语言解释转为有限概念/错误候选和逐字证据片段，例如 `confuses_base_and_result`。宿主检查证据确实存在、引用位置有效、概念在当前图谱中。Qwen 的自报“置信度”不当作概率；没有校准集时保留未知。

在人工复核的小样本上训练轻量多标签观测头，标注同义解释、错误解释和无法判断，按题目/学生隔离测试集。其概率经过独立校准后才进入概率推理；现有 0.6B 可作提取器候选，而不是无条件的判卷裁判。

### 符号部分

建立有类型的事实与关系：变量、数学表达式、定义、前提、知识点依赖、解释中的主张。采用受限 AST/表达式解析及符号或数值反例检查，禁止 `eval` 执行学生文本。

例如 `log_a(b)=c ⇔ a^c=b` 的应用必须同时检查 `a>0`、`a≠1`、`b>0`。学生说“底数可以为 1”，会产生明确的前提冲突；仅缺少说明时标为“证据不足”，不能自动判错。

把神经输出作为带概率的观测接入小型因子图/概率逻辑网络；候选知识状态由观测似然与显式约束共同计算，关系或噪声参数通过标注样本的似然/损失拟合。数学有效性和用户授权是硬约束，学生行为与知识依赖是可学习的软关系。首次可用小图枚举完成精确边缘化，不必先引入复杂框架。

这一步必须出现**实际计算的约束传播或概率推理**与推导路径，不能只有“LLM 返回 JSON，随后 if/else 选模板”就声称完成神经符号融合。首版可分阶段训练；端到端可微学习属于扩展方向，不冒充已实现 DeepProbLog。

### 输出示例（字段示意，不是学生实测）

```json
{
  "status": "needs_check",
  "concept": "logarithm_definition",
  "evidenceIds": ["explanation-17"],
  "neuralCandidates": ["base_domain_confusion"],
  "symbolicTrace": ["read_claim:base=1", "check:base!=1", "contradiction"],
  "missingEvidence": ["independent_transfer_attempt"],
  "nextCheck": "请说明底数为1时，为什么无法唯一确定指数。"
}
```

**验收**：同义表述、数学等价式、错误前提、反例、互相矛盾的多段解释、提示词注入、超出子域和无法解析文本。报告错误接受率、错误拒绝率、UNKNOWN 比例；每条解释可重放得到同一结论。

## 8. 演示与评估设计

### 一条可讲清的演示链路

学生答对一道对数选择题，但解释把底数与结果混淆 → 神经模型提出概念候选 → 符号检查找到不相容的关系 → 认知模型保留“答案正确但概念未确证” → 选择一个针对性核查问题 → 新题独立作答 → 更新后验并保留全过程证据。

另一条轨迹使用分步提示后答对，第三条独立答对且能解释。三条轨迹不能得到同一画像。当前没有真实学生证据时，用明确标记的合成轨迹演示这一区别。

### 对照组

1. 当前固定规则与模板。
2. 仅神经分类/模型路由。
3. 神经观测 + 概率认知状态。
4. 加入符号约束与推理路径。
5. 在可识别的数据条件下加入介入效果估计。

评估分别回答：下一题预测是否更准且校准；错误推断是否减少；UNKNOWN 是否合理；解释能否复现；提示后是否有独立迁移；延迟与资源是否可接受。移除任一核心模块后没有实质变化，需要重新审视模块是否真正参与计算。

### 数据纪律

按学生/会话分组、按时间切分；同一道题的同义改写与同源合成轨迹不跨训练/测试集。模型输出或规则生成的标签必须保留其来源，不循环证明自身正确。情绪历史样本与数学题库不强行按 ID 对齐。

现有数据不足以证明个性化因果效果，首版交付的是可运行、可证伪的机制与数据采集/评估条件。真实学习效果需要后续授权研究数据和独立复核。

## 9. 方法参考

- [Deep Knowledge Tracing，NeurIPS 2015](https://proceedings.neurips.cc/paper/2015/hash/bac9162b47c56fc8a4d2a519803d51b3-Abstract.html)：提供用序列神经网络建模知识追踪的研究路线；本项目建议先用可解释小模型作为基线，数据充分后比较。
- [DeepProbLog，NeurIPS 2018](https://proceedings.neurips.cc/paper/2018/file/dc5d637ed5e62c36ecb73b654b05ba2a-Paper.pdf)：神经谓词与概率逻辑推理结合的原始研究；本项目小图实现是借鉴其分工，不等同于实现该框架。
- [Doubly Robust Policy Evaluation and Learning，ICML 2011](https://icml.cc/2011/papers/554_icmlpaper.pdf)：上下文行动日志的离线策略评估方法；使用前必须检查本项目的识别、重叠和记录条件。

以上文献支持方法方向，不构成“本项目已实现”“对本项目数据一定有效”的证据。

### 模块间必须对齐的接口

- 证据层输出 `EvidenceBatch`：来源、时间、任务与知识点、辅助条件、可判分状态、授权用途。
- 神经符号层输出 `ReasoningResult`：主张、证据引用、约束状态、推理路径、未解决冲突；推断主张不能改写原始事实。
- 认知层输出 `CognitiveBelief`：知识点后验、参数来源、版本与未知项；暂态认知状态不覆盖长期三维画像的顶层结构。
- 因果层输出 `EffectEstimate`：目标比较、适用情境、估计值及区间、识别假设、数据等级或不可估计原因。
- 决策层输出 `DecisionTrace`：允许动作、选定动作、真实分配概率（适用时）、状态与证据版本、结果观察窗。历史缺失的选择概率保持缺失。

这些名称为拟议契约，实施时再固定字段类型。状态更新、解释和效果评估共享证据 ID，但同一作答派生出的答案判分与模型解释不能被当成两份独立证据重复放大置信度。

### 整体交付分三层

1. **机制原型**：P1—P4 在小子域真实参与计算，P5 在模拟环境验证；可以完整演示“证据—状态—帮助—更新”。
2. **工程闭环**：P6 接入电脑端，P7 验证回归、离线、可重放和模块贡献；允许对比结果不优于基线，必须如实记录。
3. **教学效果证据**：另有授权的真实纵向与介入数据，完成预先设计的效果评估后，才讨论真实学习提升或因果优势。

第一、二层是当前可推进的建设目标。第三层不以现有合成数据或精选演示代替。最终算法、样本规模与效果门槛根据试点数据和资源确定，不在规划阶段编造性能承诺。
