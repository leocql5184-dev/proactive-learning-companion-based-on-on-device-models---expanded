# 公开上传审计（2026-10-01）

## 发现与处理

| 项目 | 风险 | 本次处理 |
| --- | --- | --- |
| `build-profile.json5` 的签名口令字段与 `signing/` | 签名身份/密钥泄露 | 公开导出生成无签名配置；原配置和密钥留本地 |
| `.codex/`、`.tools/`、本机路径与 Git 历史 | 泄露机器/开发者环境，别人无法复现 | 导出不含这些本机配置和 `.git` |
| `outputs/`、`work/`、`submission/` | 调试上下文、学习记录、签名产物、超大包 | 全部导出排除；推理必需的 3 个数值 JSON 单独复制到 `assets/guidance` |
| 学习日志、行为画像种子 | 来源标识和二次分发许可不清 | 排除 `data/`、行为种子、原始/派生 jsonl；不删除本地文件 |
| 默认启动只支持 MindSpore，GGUF 不存在 | 源码下载后无法按新目标运行 | 默认恢复 GGUF；固定地址下载、SHA 校验、可选 MS 保留 |
| 网页服务泄露 workspaceRoot | 同机访问者取得本机路径 | 健康接口删除绝对根目录 |
| 内嵌数学题的公开分发授权 | 自有代码 MIT 不等于题目获得许可 | 标注授权未确认，作为发布前材料门槛 |

## 已有安全边界与剩余限制

回环监听、Host/Origin 检查、随机引擎密钥、静态文件白名单、模型输出校验均保留。该应用不面向公网部署。本机同用户进程可以伪造 Origin；浏览器扩展可以读取页面；localStorage 和日志不加密。这些边界不能表述为绝对隐私。

公开导出扫描只报告文件路径和匹配类别，不打印秘密值。规则能发现常见令牌、私钥、敏感配置和禁止文件，并非完整渗透测试或零漏洞保证。原仓库历史未改写，也没有上传 GitHub；必须从新导出树创建公开仓库。

实际运行、解压后验证与测试结论见 `docs/RELEASE_VALIDATION.md`（完成本次验证后生成）。
